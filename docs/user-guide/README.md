# CareConnect user documentation

CareConnect helps people who are deaf or hard of hearing keep track of their medicines, appointments and the people who care for them. Every alert you get from CareConnect shows up on screen as words and a colour flash, and on a phone you also feel a vibration. You never need to hear anything.

These pages are for the people who use CareConnect: care recipients, their caregivers and anyone helping them set it up. If you want to build or change the app, see the [project README](../../README.md).

## Which version should I use?

All versions have the same screens and the same two roles (care recipient and caregiver).

| You have… | Use | Why |
|:----------|:----|:----|
| Any phone, tablet or computer with a modern browser | **The web app**, <https://careconnect-swen661.vercel.app> | Nothing to download. Install it from the browser to get its own icon. It is the only version that keeps all your changes between visits. |
| An Android phone (Android 7.0 or newer) | The web app, or the **Android app** (APK) | The Android app gives the strongest vibration patterns. |
| An iPhone or iPad | **The web app**, added to your Home Screen | The iOS builds are unsigned, so an iPhone can't install them. |
| A Mac with Apple silicon (M1 or newer) | The web app, or the **macOS desktop app** | The desktop app adds a native menu bar and keyboard shortcuts. |
| A Windows 10 or 11 PC | The web app, or the **Windows desktop app** | See the note about the Windows installer in [Installing CareConnect](installation.md#windows). |

## Before you start

- **CareConnect is a demonstration.** It starts with sample data for a care recipient called Margaret, and nothing you enter is sent to a server. Do not use it to manage real medicines. Always follow the advice of your doctor or pharmacist.
- **Any well-formed email address and password signs you in.** There is no real account behind it. See the [FAQ](faq.md#accounts-and-privacy).
